## ติดตั้งระบบอัปเดตครั้งแรก

คัดลอกเนื้อหาใน `pc/moonloader/` ไปยังโฟลเดอร์ `moonloader` ของเกม ให้คงโครงสร้าง `lib/` และ `resource/` เดิม จากนั้นโหลด Lua ใหม่หรือเปิดเกมใหม่

เปิด `/thcodecui` → ตั้งค่าทั่วไป → **ตรวจเวอร์ชัน**

- ถ้ามีรุ่นใหม่ จะแสดงรายละเอียดและปุ่ม **ติดตั้งและโหลดใหม่**
- ดาวน์โหลดจาก commit ที่ระบุแน่นอน ตรวจขนาดและ SHA256 ครบทุกไฟล์ก่อนเปลี่ยนไฟล์ใช้งาน
- สำรองเฉพาะไฟล์ที่อัปเดตเป็น ZIP พร้อม metadata ก่อนติดตั้ง ถ้าเขียนไฟล์ไม่สำเร็จจะคืนชุดก่อนหน้า
- กด **ย้อนรุ่นก่อน** เพื่อคืนไฟล์จากอัปเดตล่าสุด โหลด Lua ใหม่หลังติดตั้ง/ย้อนกลับ
- ไม่ตรวจหรือดาวน์โหลดอัตโนมัติตอนเปิดเกม ไม่ส่งข้อความแชตออกเอง
- รุ่นนี้ไม่เปลี่ยน ASI หรือ DLL ที่เกมโหลดอยู่ หากรุ่นใดต้องใช้ ASI อื่น ตัวอัปเดตจะปฏิเสธและให้ติดตั้งแยก

สถานะภายในอยู่ใน `moonloader/.thaichat-update/` ส่วน ZIP อยู่ภายนอก moonloader ที่ `%LOCALAPPDATA%/ThaiChatBridge/backups/` เป็นค่าเริ่มต้น สามารถกำหนด `backup_directory` ใน `.thaichat-update/settings.json` บนเครื่องตัวเองได้ ไฟล์นี้ไม่ถูกดาวน์โหลดทับ

ตัวอย่าง settings บนเครื่องพัฒนา:

```json
{"backup_directory":"C:/PJ ThaiChatBridge/backups"}
```

## โครงสร้างเผยแพร่

- `updates/stable.json` — เวอร์ชันล่าสุด ข้อกำหนด ASI และ SHA256 ของแต่ละไฟล์
- `pc/moonloader/` — ไฟล์ของปลั๊กอินที่อัปเดตได้
- manifest ตรึง `commit` แบบ SHA 40 หลัก ตัวดาวน์โหลดจึงไม่อ่านไฟล์จาก main ที่กำลังเปลี่ยนระหว่างอัปเดต
- ไม่มี token หรือบัญชี GitHub ในตัวเกม ใช้ repo สาธารณะผ่าน HTTPS
- ไม่เผยแพร่ logs, ประวัติแชต, การตั้งค่าส่วนตัว หรือไฟล์เกมของผู้ใช้

SHA256 ตรวจว่าไฟล์ตรงกับ manifest; ความน่าเชื่อถือของรุ่นขึ้นกับบัญชีและ repository นี้ ไม่ใช่ระบบลายเซ็นแยกต่างหาก
