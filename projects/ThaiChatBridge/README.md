# ThaiChatBridge

แกนข้อความไทย ฟอนต์ codec อิโมจิ ไอคอน แชตและบอลลูน แยกจากตัวอัปเดตและเครื่องมือ

ชุดสาธารณะในช่องเดิมเป็น R25 test2; R26 Codex test2 เป็นงานทดลอง 3D ในเครื่องพัฒนา ยังไม่รวมในแพ็กเกจสาธารณะนี้ การยืนยัน 3D มาจาก shared _chat renderer ไม่ได้ยืนยัน native SAMP hook ทุกเส้นทาง

ดู [runtime assets](../../native-pc/) และ [หน้าหลัก](../../README.md) เลือกแพ็กเกจตามรุ่น ห้ามคัดลอกทั้งโฟลเดอร์ assets หรือโหลด core สองรุ่นพร้อมกัน
