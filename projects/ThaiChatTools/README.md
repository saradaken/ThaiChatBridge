# ThaiChatTools

เครื่องมือ Codec Lab / Bento สำหรับดูงบไบต์ เปรียบเทียบ codec ตั้งค่าและทดสอบ ใช้ `/thcodecui` แยกจากตัวอัปเดต `/thupdate`

ไฟล์หลักคือ ThaiChatTools.lua และ lib/thaichat/native_tools.lua, codec_lab.lua, cef_view.lua พร้อมทรัพยากร CEF ตามรุ่น เครื่องมือไม่ใช่แกนแชตและไม่จำเป็นสำหรับการถอดข้อความด้วย ASI standalone รุ่นปัจจุบัน

[ชุด assets เดิม](../../native-pc/moonloader/) มีส่วนประกอบหลายรุ่น อย่าคัดลอก launcher updater รุ่นเก่าปน bootstrap รุ่นใหม่ ดู [หน้าหลัก](../../README.md)
